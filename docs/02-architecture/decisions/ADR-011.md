# ADR-011 — Toda foto é convertida pro padrão do site antes de gravar

## Contexto

Foto de concessionária e galeria de veículo chegam em qualquer formato/tamanho que o cliente
enviou.

## Decisão

`ImageOptimizer` (GD) converte pra WebP e redimensiona (até 1600px no lado maior) antes de gravar
no MinIO — nunca o arquivo cru. A conversão roda no worker, fora do request.

## Consequências

- Toda foto servida pelo site tem formato/peso previsível, sem depender de o que cada cliente
  mandou.
- Processamento pesado (decode, resize, encode) nunca bloqueia a resposta HTTP — o endpoint só
  valida MIME/tamanho e enfileira.
- O mesmo `ImageOptimizer` é reaproveitado sem alteração entre foto de concessionária e galeria de
  veículo — um optimizer, dois chamadores.
