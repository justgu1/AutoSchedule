# ADR-012 — SPA 100% client-rendered, sem SSR

## Contexto

O frontend é uma SPA React montada via `createRoot` — todo conteúdo depende de JavaScript rodar no
browser.

## Decisão

Aceitar isso como limitação conhecida por ora, em vez de investir em SSR (Next.js/Remix ou
equivalente) nesta fase do projeto. `index.html` tem um `<noscript>` avisando o usuário, mas não
há conteúdo funcional sem JS.

## Consequências

- Navegador sem JavaScript ou leitor que não executa script não vê conteúdo nenhum além do aviso.
- SEO de página pública (catálogo, veículo, concessionária) depende de crawler que executa JS.
- Migrar pra SSR entrega HTML já renderizado no primeiro request — fica registrado como pendência
  em [`Worklist.md`](../../../Worklist.md), não como decisão revertida.
