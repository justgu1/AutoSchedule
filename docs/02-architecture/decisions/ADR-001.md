# ADR-001 — Application não recebe HTTP Request

## Contexto

Casos de uso precisam ser independentes do protocolo de entrada — hoje é HTTP, mas o próprio
`bin/worker.php`/`bin/scheduler.php` já chamam os mesmos casos de uso sem request nenhum.

## Decisão

A camada Application recebe DTOs e `ActorContext` (quem, com que role, de onde), nunca o objeto
`Request` do Infrastructure/Http.

## Consequências

- Application permanece independente de HTTP — o mesmo caso de uso serve o controller e o worker.
- Testes de caso de uso não simulam `Request`.
- Controller fica responsável pelo transporte: validar corpo, montar `ActorContext`, serializar
  resposta.
