# ADR-004 — Duração do agendamento é fixa em 60 minutos

## Contexto

O processo comercial trata toda visita/teste-drive como uma janela de uma hora, independente do
veículo.

## Decisão

`Appointment::DURATION_MINUTES = 60`, constante de domínio — não é campo escolhido pelo cliente
nem configurável por concessionária.

## Consequências

- O motor de disponibilidade (`AvailabilityCalculator`) gera slots de hora em hora, sem precisar
  perguntar duração a ninguém.
- O prazo de devolução do teste-drive é sempre `scheduled_at + 60min`, nunca a hora real da
  retirada — chegar atrasado pra retirar não estica o prazo (AG-008).
- Se o negócio um dia precisar de duração variável, isso deixa de ser constante e vira campo — não
  é decisão que se reverte de graça, mas é a que reflete a regra real hoje.
